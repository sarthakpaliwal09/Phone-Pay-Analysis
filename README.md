# Consumer Complaints Analysis | Excel

## Project Overview
This project focuses on analyzing consumer complaints using Microsoft Excel. The objective is to identify complaint trends, understand consumer issues, evaluate company responses, and generate meaningful business insights through data analysis and visualization.

## Dataset Overview
- Total Records: 62,516
- Tool: Microsoft Excel
- Data: Consumer complaint records
- Analysis: Complaint trends, products, issues, response types, and resolution time.

*Note: Confirm and mention the original dataset source before publishing. The workbook's Data Description sheet refers to CFPB data.*

## Tools & Techniques Used
- Microsoft Excel
- Data Cleaning and Preparation
- Pivot Tables
- Excel Charts
- Data Analysis
- KPI Calculations
- Date and Time Analysis

## Project Workflow

1. Data Understanding – Reviewed the dataset structure and column descriptions.
2. Data Preparation – Worked with complaint dates, response categories, and calculated fields.
3. Data Analysis – Used Pivot Tables to analyze complaints across different categories.
4. Data Visualization – Created charts to present complaint trends and response patterns.
5. Insight Generation – Identified important trends related to complaint issues and company responses.

## Key Analysis & Insights

- Identified the most frequently reported complaint issues.
- Analyzed complaint distribution by financial product.
- Evaluated different company response categories.
- Identified complaints that were still in progress.
- Analyzed the most frequently used complaint submission channel.
- Calculated the percentage of late responses.
- Identified same-day complaint resolutions.
- Analyzed average complaint response time.

## Dashboard
The Excel dashboard includes visualizations for:
- Yearly and Monthly Complaints
- Number of Complaints by Product
- Company Responses to Consumers

## Key Findings

- Total complaints analyzed: 62,516.
- Most frequently reported issue: Managing an account (15,109 records in the analysis).
- Complaints submitted through Web: 45,424.
- Complaints resolved on the same day: 49,634.
- Complaints still marked In Progress: 1,494.
- Complaints resulting in monetary relief: 14,697.
- Late response percentage: Approximately 6.23%.
